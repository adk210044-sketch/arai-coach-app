このドキュメントは、App Store / Google Play 掲載用スクリーンショット(9枚セット)の
制作をデザイン担当(別のAIチャット/デザイナー)に依頼するための指示書です。
そのままコピーして渡してください。

> **本バージョンの位置づけ**: 姉妹アプリ「衛生管理者 1日9問」のリニューアル版スクリーンショット
> (ダーク背景×ゴールドアクセント×大きな数値訴求のフォーマット)を踏襲し、
> 「あらいコーチ」の実際のコンテンツ数値に置き換えて9枚構成で作成する。
> `04_screenshot_design_brief.md`(旧5枚構成・マスコット中心)は参考として残すが、
> 今回のストア掲載はこちらのv2(9枚構成)を正とする。

> **v2.1での変更点**:
> - 過去問数の表記を「1,030問」→「**1,000問以上**」に統一(今後の問題追加を見据え、具体的な数を固定しないため)
> - 各カットの文字要素を「英字タグラベル → 見出し → サブコピー → データブロック」の4段構成に統一し、重複表現を整理

## 0. アプリ概要(前提情報)

- アプリ名: 「あらいコーチ」(衛生管理者試験対策アプリ)
- アプリアイコン: 青地に白フチの丸、中に青いアライグマの顔+下部に「衛生管理」の文字
- マスコットキャラクター: 青いアライグマの「あらいコーチ」(コーチ風ユニフォーム+ホイッスル+問診票を持っている)
- 対応試験区分: 第一種・第二種 両対応
- ブランドカラー(アプリ内): ブルー系(メイン `#0369E5`、ダーク `#0057C2`)
  - ※ただし今回のスクリーンショットは姉妹アプリに合わせて**ダークネイビー×ゴールド**の高級感あるトーンで統一する(下記「2. 配色・トンマナ」参照)

## 1. 参考にするフォーマット(姉妹アプリ「衛生管理者 1日9問」)

姉妹アプリの9枚構成は完成度が高いため、**レイアウト構造・情報設計・配色トーンをそのまま踏襲**してください。

### 踏襲すべきポイント

1. **背景**: ダークネイビー(濃紺〜黒に近いブルー)の単色〜ごく薄いグラデーション。大きな円形の装飾ライン(輪っか)を背景に薄く配置
2. **上部左**: 英字の小さいタグラベル(例:`PAST EXAMS・ANSWERS`)。カットごとにテーマが一目でわかる索引の役割
3. **上部右**: 金色の円形エンブレム(本アプリの訴求文言に差し替え)
4. **見出し**: 白文字+ゴールド文字を使い分けた大きな太字見出し(2行、長くても3行)。ゴールド文字は数字や最重要キーワードにのみ使う
5. **サブコピー**: 見出し下に1行だけ、補足説明を添える(2つの意味を詰め込まない)
6. **データブロック**: サブコピーの下に、黒系カード(角丸)で区切った「数値+短い説明」を1〜2個、横並びで配置
7. **画面キャプチャ**: データブロックの下に、**スマホ実機フレーム(ノッチ付きの黒フレーム)に入れたアプリ画面キャプチャ**を大きく配置。画面は全体の60〜70%程度の高さを占め、下端はキャンバスの外に切れてもよい(=大きく・大胆に見せる)
8. **画面を2枚重ねる場合**(姉妹アプリ3枚目のパターン): 奥の画面を少し左にずらし小さく、手前の画面を大きく正面に配置。どちらも実機フレームに入れる
9. **チェックリスト風の訴求**(姉妹アプリ9枚目のパターン): 最後の1枚はアイコン+短い訴求文を縦に並べたチェックリストで要点を総括し、末尾に一番大きな決めゼリフを置く

### 本アプリで変更する点

- 配色はグリーン系ではなく、**あらいコーチのブランドカラーであるネイビー〜ダークブルー系**に置き換える
- 右上の金色エンブレムの文言は「リニューアル」ではなく、本アプリの状態に応じた文言(例:「2026年受験対応」)にする
- 1枚目(カバー)には、姉妹アプリのロゴ中心構成ではなく、**本アプリのポイントを端的にまとめた「概要訴求カバー」**を作る(詳細は下記カット1を参照。ユーザー指定のため最重要)
- マスコット「あらいコーチ」のイラストを、9枚のうち**2〜3枚程度**に差し込み、ブランドの親しみやすさを補強する(姉妹アプリにはマスコット演出がないため、ここは「あらいコーチ」独自の強みとして追加する)

## 2. 配色・トンマナ

| 要素 | 指定 |
|---|---|
| 背景ベース | ダークネイビー(濃紺〜ごく暗いブルーグレー、例 `#0A1930`〜`#11213B`) |
| 背景装飾 | 大きな円形の薄い輪っか・波紋を背景に1〜2本、控えめに配置(姉妹アプリの意匠を踏襲) |
| 英字タグラベル | ゴールド(`#D9B86C`前後)の小文字トラッキング広めの英字 |
| 見出し文字 | 白(`#FFFFFF`)+ 強調箇所はゴールド(`#D9B86C`前後) |
| サブコピー | 白〜ライトグレー(`#C9D3E0`前後) |
| データカード背景 | 黒に近い濃紺(`#0E1C33`前後)、角丸、薄い金色 or 白の縁取り線 |
| エンブレム(右上) | 金色の円形バッジ、姉妹アプリと同じ円形スタンプ風デザイン |
| スマホ実機フレーム | 黒フレーム+ノッチ(姉妹アプリと同じ)。画面内は実際のアプリUI(白〜薄い水色背景のまま、加工しない) |

## 3. 全体仕様

- **サイズ**: iPhone 6.9インチ 1320×2868px(または1290×2796px)。Android兼用で9:16縦長に統一。
- **枚数**: 9枚
- **言語**: 日本語のみ(タグラベルのみ英字)
- **フォント**: 見出しは極太のゴシック体(視認性最優先)。画面キャプチャ内の文字は実際のアプリUIをそのまま使用(加工しない)。
- **画面キャプチャの大きさ**: 姉妹アプリ同様、**キャンバスの60〜70%の高さを占める大胆なサイズ**にする。小さく収めすぎない。
- **各カットの文字要素は、以下4段構成に統一する**(カット1・9の総括カットのみ例外あり):
  1. 英字タグラベル(1行)
  2. 見出し(2行、ゴールド強調つき)
  3. サブコピー(1行のみ)
  4. データブロック(1〜2項目)

## 4. 各カット詳細(9枚)

### カット1:カバー(アプリ概要訴求) ※最重要
姉妹アプリのロゴ中心構成とは異なり、**「あらいコーチ」のポイントを端的に・見やすくまとめた概要カバー**にしてください。

- **タグラベル**: `OVERVIEW`
- **右上エンブレム**: 「2026年受験対応」
- **上部ロゴ**: アプリアイコン(青いアライグマ+「衛生管理」ロゴ)を小さく配置 + アプリ名「衛生管理者試験対策 あらいコーチ」
- **見出し**:
  ```
  1,000問以上と、
  AIコーチで
  一発合格へ。
  ```
- **サブコピー**: 「第1種・第2種、どちらも対応。」
- **データブロック(4項目、チェックリスト形式)**:
  - 1,000問以上 ー 過去問・解説を完全収録
  - AI診断 ー 弱点分析&合格可能性
  - 無料 ー 50問・会員登録不要でお試し
  - 1・2種 ー 両試験区分に対応
- **マスコット**: `arai_coach.png`(基本ポーズ)を下部に小さく添える
- **画面キャプチャ**: このカットのみ、画面キャプチャは入れなくてもよい(ロゴ+テキストのみの概要訴求でOK)

### カット2:過去問収録数の訴求
- **タグラベル**: `PAST EXAMS・ANSWERS`
- **見出し**:
  ```
  1,000問以上の
  過去問&解説を収録
  ```
- **サブコピー**: 「第1種・第2種、どちらも対応。」
- **データブロック**: 「毎回更新 ー 最新試験まで順次追加」
- **画面キャプチャ**: 問題演習画面(問題文+選択肢)を実機フレームで大きく表示。姉妹アプリ3枚目のように、奥に正解画面をもう1枚重ねて見せてもよい
- **マスコット**: なし

### カット3:模擬試験の訴求
- **タグラベル**: `MOCK EXAM`(エンブレム風に`NEW`を添えてもよい)
- **見出し**:
  ```
  本番同様の、
  模擬試験。
  ```
- **サブコピー**: 「好きな回を選んで、本番と同じ構成・時間で。」
- **データブロック(横並び2つ)**:
  - 第1種 44問/3時間
  - 第2種 30問/3時間
- **画面キャプチャ**: 模擬試験画面(タイマー・進捗・問題文)を実機フレームで大きく表示
- **マスコット**: `arai_coach_perfect.png`(トロフィー)を画面の脇に添える

### カット4:AI弱点分析・合格可能性診断の訴求
- **タグラベル**: `PASS DIAGNOSIS`(エンブレム風に`NEW`を添えてもよい)
- **見出し**:
  ```
  合格ラインまで、
  あと何%?
  ```
- **サブコピー**: 「科目別の正答率を、公式合格基準と比較。」
- **データブロック(横並び2つ)**:
  - 40% ー 各科目の合格基準
  - 60% ー 総合の合格基準
- **画面キャプチャ**: 分析画面(合格可能性の円グラフ+科目別正答率バー)を実機フレームで大きく表示
- **マスコット**: `arai_coach_motivate.png`(ガッツポーズ)を小さく添える

### カット5:苦手復習の訴求
- **タグラベル**: `WEAK POINTS`
- **見出し**:
  ```
  苦手だけを、
  ピンポイントで復習。
  ```
- **サブコピー**: 「間違えた問題は自動記録。いつでも解き直せる。」
- **データブロック**: 「自動記録 ー ブックマークでいつでも管理」
- **画面キャプチャ**: ブックマーク復習画面 or 苦手分野一覧画面を実機フレームで表示
- **マスコット**: `arai_coach_incorrect.png`(困り眉だが優しい表情)を添える ※「間違えても大丈夫」という安心感の演出

### カット6:学習記録(カレンダー)の訴求
- **タグラベル**: `STUDY LOG`
- **見出し**:
  ```
  続けた日々が、
  一目でわかる。
  ```
- **サブコピー**: 「毎日の結果を記録。通勤中・休憩中のスキマ時間で。」
- **データブロック**: 「連続記録 ー バッジ&ストリークでやる気を維持」
- **画面キャプチャ**: カレンダー画面(学習記録・連続日数表示)を実機フレームで表示
- **マスコット**: なし

### カット7:全コンテンツ一覧の訴求
- **タグラベル**: `ALL CONTENTS`
- **見出し**:
  ```
  1,000問以上を、
  使い切る。
  ```
- **サブコピー**: 「第1種・第2種&最新問題も収録。」
- **機能アイコンリスト(2×2、データブロックの代わりに配置)**:
  - 📖 過去問演習
  - ⏱ 模擬試験
  - 📊 合格可能性診断
  - 🎯 苦手復習
- **画面キャプチャ**: 模擬試験「回を選ぶ」一覧画面、または演習メニュー画面を実機フレームで表示
- **マスコット**: なし

### カット8:AIコーチ(チャット)の訴求
- **タグラベル**: `AI COACH`
- **見出し**:
  ```
  迷ったら、
  コーチに質問。
  ```
- **サブコピー**: 「わからないことは、いつでも聞ける。」
- **データブロック**: 「相談し放題 ー やさしい言葉でいつでも解説」
- **画面キャプチャ**: コーチ(チャット)画面を実機フレームで表示
  - ⚠️ 「ユーザー側でGemini連携が必須」等の注記文言は、このスクリーンショット上には写り込ませないこと(不安を与えるため除外)
- **マスコット**: `arai_coach.png`(基本ポーズ)を画面の脇に添える

### カット9:クロージング(総括+あらいコーチ) ※姉妹アプリ9枚目を踏襲
- **上部**: アプリアイコンを中央に大きめ配置 + アプリ名
- **見出し**:
  ```
  正しいやり方で、
  確実に、
  合格に近づく。
  ```
- **チェックリスト(4項目)**:
  - ✅ 過去問・解説1,000問以上を収録
  - ✅ 第1種・第2種 両対応
  - ✅ 模擬試験・合格可能性診断つき
  - ✅ AIコーチにいつでも質問できる
- **区切り線**
- **最後の決めゼリフ(最大サイズ)**:
  ```
  今日から、あらいコーチ。
  ```
- **マスコット**: `arai_coach_perfect.png`(トロフィーで祝福)を下部に大きめに配置。画面キャプチャは入れない(姉妹アプリ9枚目と同様、ロゴ+テキスト+マスコットのみの締めカット)

## 6. 絶対に守ってほしいNG事項

- ❌ 画面キャプチャを小さく収めすぎない(姉妹アプリ同様、キャンバスの60〜70%の高さで大胆に見せる)
- ❌ 背景とスマホ画面の境界が曖昧にならないようにする(ダーク背景+実機フレームの黒縁取りで、自然と境界がはっきりする構成なので、フレームを省略しないこと)
- ❌ **過去問の問題数は必ず「1,000問以上」で統一し、「1,030問」等の具体的な数値は使わない**(今後の問題追加を見据えた表記)
- ❌ カット8(AIコーチ)に「Gemini連携が必須」等のハードルを感じさせる注記を写り込ませない
- ❌ カット1(カバー)は、情報を詰め込みすぎず、見出し+データブロック4項目+マスコットの範囲に収め、「端的に・見やすく」を最優先する
- ❌ 各カットの文字要素は「タグラベル→見出し→サブコピー→データブロック」の順番・分量を守り、1つの要素に複数のメッセージを詰め込まない
- ❌ 9枚全体を通して配色トーン(ダークネイビー×ゴールド)がブレないようにする

## 7. 補足:姉妹アプリとの差別化ポイント

姉妹アプリ「衛生管理者 1日9問」は「1日9問・7日間で1回分」という**毎日の習慣化**を前面に出した訴求でした。
「あらいコーチ」は以下の点を独自の強みとして、画面構成の端々で匂わせてください(無理に全カットに入れる必要はありません):

- AIコーチ(マスコットキャラクター)による、やさしい解説・会話形式のサポート
- 合格可能性診断・弱点分析など、データに基づく学習ナビゲーション
- 初めての資格試験でも迷わないシンプルな設計
