# Google Play / App Store 掲載用テキスト(改訂版 v2)

> 改訂方針:以下4点を軸に、競合アプリ調査を踏まえて作り直し
> 1. 痒い所に手が届く(具体的な悩み→具体的な解決策を対にして提示)
> 2. 初心者にもわかりやすく、安心できる(専門用語を避け、不安を先回りして解消)
> 3. 合格を目指す期待が持てる(数字・実績・ビフォーアフターで説得力を出す)
> 4. 試しにダウンロードしてみたいと思える(無料で試せる範囲を明確に、ハードルを下げる)

## 詳しい説明(改訂版)

```
「参考書、どこから手をつけていいか分からない…」
「間違えた問題、なぜ間違えたのかよく分からないまま次に進んでる…」
「一人だと続かない。今日も結局やらなかった…」

その悩み、「あらいコーチ」が全部拾いにいきます。

衛生管理者試験(第一種・第二種)に特化した、過去問1030問とAI解説つきの学習アプリです。
令和元年〜最新回まで収録、スキマ時間だけで合格ラインを目指せます。


■ こんな「痒い所」、ありませんか?

・分厚いテキストを買ったけど、結局3日で止まっている
 → アプリならスマホ1つ。通勤時間・休憩時間だけで進められます

・過去問を解いても、「なぜ不正解か」がピンとこない
 → 全問に解説付き。さらにAIコーチが「どこを勘違いしやすいか」まで教えます

・第一種と第二種、自分がどっちを勉強すべきか分からない
 → 試験区分をアプリ内でいつでも切り替え可能。迷わず進められます

・毎日続ける自信がない
 → 1回5問からでもOK。連続記録・バッジで「続いている実感」を可視化します


■ 初めての資格試験でも安心な理由

このアプリは「勉強が得意じゃない人」を一番に考えて作りました。

・むずかしい専門用語は、あらいコーチが日常の言葉に置き換えて解説
・間違えても責めません。「ここだけ覚え直せば大丈夫だよ」と次の一歩を示します
・迷う操作がないシンプル画面。資格試験アプリが初めての方でもすぐ使えます
・「何から始めればいいか分からない」は、ホーム画面の「今日のタスク」にお任せ

スマホ操作が苦手な方でも、開いた瞬間に「今日やること」が分かる設計です。


■ 合格への距離が、数字で見えてくる

・AIが解答履歴から弱点分野を自動分析
・分野ごとに「合格基準まであと何%」を表示
・今の実力から「合格可能性」をリアルタイムで診断
・本番と同じ形式の模擬試験で、試験当日の感覚を先取り体験

「あと何をやれば受かるのか」が分からない不安を、見える化してなくします。
関係法令・労働衛生・労働生理、すべての分野を効率よくカバーできます。


■ まずは無料で、試してみてください

・会員登録不要、ダウンロードしてすぐに問題演習をスタートできます
・無料プランでも過去問50問・AIコーチへの質問が毎日お試しいただけます
・「自分に合うかどうか」を、お金をかける前に確認できます
・継続して使いたい方には、プレミアムプラン・3か月集中パックもご用意(7日間無料トライアル付き)


■ 飽きずに続けられる工夫も

・問題を解くたびにバッジを獲得できるゲーム感覚設計
・毎日の学習をムリなく記録できるカレンダー機能
・間違えた問題だけを集めた「ブックマーク復習」
・本番形式で実力試しができる「模擬試験モード」


■ 最新情報も、しっかり追いかけています

法改正や最新の出題傾向に合わせて、過去問・解説は定期的にアップデートしています。
「古いアプリで対策して損をした」ということがないよう、常に最新の状態を保ちます。


衛生管理者試験は、正しいやり方で取り組めば、初めてでも十分に合格できる試験です。
「あらいコーチ」と一緒に、今日の5問から始めてみませんか?
```

## レビュー対策として意識したポイント

| 競合でよくある不満・ユーザーの不安 | 本アプリでの対応 |
|---|---|
| 何から手をつければいいか分からない | ホーム画面「今日のタスク」、悩み→解決策の対比構成で明示 |
| 解説が簡潔すぎて理解できない | あらいコーチの「やさしい言葉での解説」を具体例つきで強調 |
| モチベーションが続かない | バッジ・連続記録・カレンダー機能を明記 |
| 古い年度の問題しかない/情報が古い | 「令和元年〜最新回」+更新頻度(鮮度)の訴求を追加 |
| 課金する前に合うか試したい | 無料プランの範囲(過去問50問・AIコーチ質問)を明確に記載 |
| 初めての資格試験で不安 | 「初めての方でも安心」セクションを新設、専門用語への配慮を明記 |
| 合格できるか不安 | 弱点分析・合格可能性診断・合格基準との差分表示を数字で訴求 |
| UIが使いにくい | 「迷う操作がないシンプル画面」を明記 |
